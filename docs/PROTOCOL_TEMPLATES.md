# Protocol Templates

Protocol templates provide structure, not scientific content.

## Included Templates

- Cell Culture Protocol
- Differentiation Protocol
- Treatment Protocol
- Immunostaining Protocol
- Imaging Protocol
- RNA Extraction Protocol
- Media Preparation Protocol
- Blank Protocol

Templates include common sections:

- Overview
- Narrative instructions
- Timeline events
- Materials
- Media
- Equipment
- Expected results
- QC
- Troubleshooting
- References

## Rule

Templates must not populate reagent concentrations, timing, media recipes, expected markers, catalog numbers, or procedural details unless the content is clearly marked as example text. Researchers must add and verify scientific details before approval.
