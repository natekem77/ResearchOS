# Notebook-First Philosophy

The notebook is the laboratory bench. Everything else is a scientific instrument.

Researchers begin by thinking, sketching, pasting, dictating, and revising. Mundi should preserve that freedom instead of forcing every experiment through a fixed workflow.

## Product Rules

- New Experiment opens an empty notebook workspace.
- Metadata is optional at creation.
- Structured tools may propose timelines, conditions, samples, or protocol links.
- Tools never silently rewrite notebook content.
- Copilot suggestions require researcher approval.
- Notebook text and structured data coexist.
- Unknown values remain unknown.

## Why

Many experiments begin as incomplete scientific intent. A rigid wizard encourages premature structure and false precision. Notebook-first design allows structure to emerge when it is useful.
