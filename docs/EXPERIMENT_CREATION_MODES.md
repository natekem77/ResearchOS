# Experiment Creation Modes

ResearchOS supports multiple ways to create experiments.

Implemented now:

- Blank Experiment
- Start from Protocol
- Guided Builder

Future-ready placeholders:

- Describe Experiment
- Import Spreadsheet

The placeholder modes do not claim AI extraction or spreadsheet mapping is complete. They explain that proposed fields will require researcher confirmation before becoming active.

## Mobile UI

The Flutter New Experiment screen now opens with a creation-mode landing page. Blank and protocol-based creation use the generalized backend. The guided builder remains available for richer manual setup.
