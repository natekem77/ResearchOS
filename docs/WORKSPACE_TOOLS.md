# Workspace Tools

Workspace tools operate inside the Mundi Workspace. They assist the notebook without replacing it.

## Tool Behavior

- Desktop/tablet: tools open in a docked side panel.
- iPhone: tools open in a bottom sheet.
- The notebook remains the primary surface.
- Tool state is future-ready for persisted collapsed/expanded/last-open preferences.

## Initial Tools

- Copilot: reads notebook text and proposes actions.
- Protocols: attaches protocols and generates inherited timeline events when requested.
- Spreadsheet Import: inserts previews or future mapped imports.
- Voice: inserts transcripts into the notebook first.
- Timeline: shows generated or manual events beside the notebook.
- Conditions: shows structured conditions generated manually or by review.
- Inventory: future object-reference actions such as check stock and reserve inventory.
- Chat: future experiment-linked discussion.
- Analysis, Literature, Memory, Whiteboard: contextual scientific tools.

## Non-Destructive Rule

Tools can attach, preview, propose, or insert researcher-confirmed text. They must not silently overwrite notebook content.
